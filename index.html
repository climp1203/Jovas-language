What makes it different

Built for the modern
backend developer

Jovas combines the best of every language into one clean, expressive syntax — with AI, databases, deployment, and real-time communication built in from day one.

🤖
AI Native
Call ai.ask(), ai.sentiment(), ai.summarize() with zero setup. The first backend language with AI as a first-class citizen.
🗄️
JovasDB Built-in
A full PostgreSQL-style database engine. Tables, indexes, foreign keys, transactions, migrations — and natural language queries.
✨
Auto API Generation
Add expose to any function. Jovas auto-generates a REST endpoint, validation schema, documentation, and a curl example.
🚀
One-line Deploy
deploy.to("cloud", { region, scale }) ships your app instantly. Rollback, scale, and view logs in one call each.
⚡
Built-in Real-time
WebSocket pub/sub with realtime.sync(), realtime.broadcast(), and realtime.presence() — zero configuration needed.
🧠
Smart Errors
Every error comes with a plain-English explanation and a ready-to-use code fix. No more cryptic stack traces.
🔒
Security Module
PBKDF2 password hashing, real JWT with expiry, input validation, CORS headers, and role-based permissions — all built in.
📧
Email Module
Send emails, use built-in templates (welcome, OTP, invoice, reset), queue delayed sends, and track history natively.
🔧
Formatter + Linter
fmt.format() and lint.check() are built into the language. Catch bugs before they run — no external tools needed.

Syntax that feels

// Variables & constants
let name   = "Jovas"
const PORT = 8080

// String interpolation
let msg = "Server running on port ${PORT}"

// Functions & async
async fn fetchData(url)
    let res = await http.get(url)
    return res.body

// Pattern matching
match status
    case "active"  => print("✅ Running")
    case "stopped" => print("🔴 Halted")
    case "default" => print("❓ Unknown")

// Pipeline operator
let result = users |> filterActive |> sortByAge |> limit
// Connect to JovasDB
let db = database.connect("myapp")

// Create a table
let cols = [
    { name: "id",    type: "INTEGER", pk: true },
    { name: "name",  type: "TEXT",    nullable: false },
    { name: "email", type: "TEXT",    unique: true },
    { name: "role",  type: "TEXT",    default: "user" }
]
db.createTable("users", cols)

// CRUD operations
db.insert("users", { id: 1, name: "Alex", email: "[email protected]" })
let users = db.select("users", { role: "admin" })
db.update("users", { id: 1 }, { role: "admin" })

// Natural language queries
let active = db.ask("find all active users older than 25")
let orders = db.ask("find top 5 orders sort by total desc")

// Transactions
let tx = db.begin()
tx.insert("users", { name: "Bob" })
tx.commit()
// Password hashing (PBKDF2)
let hashed = security.hash("mypassword")
let ok     = security.verify("mypassword", hashed)

// JWT with expiry
let token   = security.jwtSign({ userId: 1 }, "secret", 3600)
let payload = security.jwtVerify(token, "secret")

// Input validation
let result = security.validate(data, {
    email: { required: true, type: "email" },
    age:   { required: true, min: 18, max: 120 },
    name:  { required: true, minLength: 2 }
})

// Role-based permissions
security.defineRole("admin", ["read", "write", "delete"])
let ok = security.permit(user, "delete")

// CORS headers
let headers = security.cors({ origins: ["https://myapp.com"] })
// Subscribe to a channel
realtime.sync("chat", fn(data)
    print("New message: ${data}")
)

// Broadcast to all subscribers
realtime.broadcast("chat", {
    from: "Alex",
    text: "Hello from Jovas!",
    ts:   time.now()
})

// Events
realtime.on("userJoined", fn(user)
    print("${user} joined the room")
)
realtime.emit("userJoined", { name: "Alex" })

// Presence — who is online
realtime.join("room-1", "user-42")
let online = realtime.presence("room-1")
print("Online: ${len(online)} user(s)")
