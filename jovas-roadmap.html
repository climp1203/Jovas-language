Section 01
How to Start Coding in Jovas
// Step-by-step flow from zero to first program
Step 01
Open the IDE
Go to the Playground at climp1203.github.io/Jovas-language/playground.html — or launch the desktop app with start.bat
Step 02
Pick an Example
Click the 📚 sidebar tab. Start with Hello World, then explore Database, Security, or AI Module
// sidebar → Examples → Hello World
Step 03
Write Your Code
Jovas uses clean indentation syntax — no semicolons, no braces. Tab = 4 spaces.
fn greet(name) return "Hello ${name}!" print(greet("World"))
Step 04
Run It
Press Ctrl+Enter or click ▶ Run. Output appears instantly in the right panel.
// Output panel → shows results // Green = success, Red = error
Step 05
Save & Build
Ctrl+S saves. Create new files with Ctrl+N. Use the file explorer to manage your project.
Step 06
Use AI Features
Call ai.ask(), ai.generate(), ai.translate() directly in your code — no API setup needed.
let r = ai.ask("explain recursion") print(r)
