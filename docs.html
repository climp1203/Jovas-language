Jovas Language
Reference

Jovas is an AI-native backend programming language designed to combine the best features of all major languages into one clean, expressive syntax — with AI, databases, deployment, security, and real-time communication built in from day one.

Version

This documentation covers Jovas v1.0.0. The language is actively developed.

Installation

Jovas requires Python 3.10 or higher. No external packages are needed for the core language.

# Clone the repository
git clone https://github.com/jovas-lang/jovas
cd jovas

# Run the demo to verify installation
python run.py

# Start the interactive REPL
python run.py repl

Quick Start

Create a file called app.jovas and run it:

// app.jovas
const APP  = "MyApp"
const PORT = 8080

fn onStart()
    log.info(["${APP} running on port ${PORT}"])

let app = server.create()
app.listen(PORT, onStart)
python run.py run app.jovas

Variables & Constants

Use let for mutable variables and const for immutable constants. Jovas is dynamically typed — no type annotations required (though optional type hints are supported).

let name    = "Jovas"      // string
let port    = 8080         // integer
let active  = true         // boolean
let data    = null         // null
const MAX   = 9999         // immutable — cannot be reassigned

// String interpolation with ${}
let msg = "Hello, ${name}! Port: ${port}"

// Null-safe access with ?.
let avatar = user?.profile?.avatar

Functions

// Basic function
fn greet(name)
    return "Hello, ${name}!"

// Async function
async fn fetchData(url)
    let res = await http.get(url)
    return res.body

// Expose as REST endpoint automatically
expose fn getUser(id)
    return db.findOne("users", { id: id })

// Optional type hints
fn add(a: int, b: int): int
    return a + b

Multiple return values

fn minmax(items)
    return min(items), max(items)

let lo, hi = minmax([3, 1, 9, 2])

Classes

class User
    fn init(name, email)
        self.name  = name
        self.email = email

    fn greet()
        return "Hi, I am ${self.name}!"

    fn toJson()
        return { name: self.name, email: self.email }

let u = User("Alex", "[email protected]")
print(u.greet())

database / db Module

JovasDB is a full PostgreSQL-style database engine built into Jovas. It persists data to .jdb files and supports tables, indexes, foreign keys, transactions, and natural language queries.

MethodReturnsDescription
database.connect(name)ConnectionOpen or create a .jdb database
db.createTable(name, cols)selfDefine a new table with schema
db.insert(table, row)rowInsert a row and return it
db.select(table, where?, order?, limit?)arrayQuery rows with optional filters
db.update(table, where, updates)intUpdate matching rows, return count
db.delete(table, where?)intDelete matching rows, return count
db.count(table, where?)intCount rows with optional filter
db.findOne(table, where)row|nullReturn first matching row
db.ask(query)arrayNatural language query
db.begin()TransactionStart a transaction
tx.commit()boolCommit transaction to disk
tx.rollback()boolUndo all transaction operations
